================================================================
  AL-DERMAL-DIAGNOSE — Full System Run Instructions
================================================================
  8 services total — start them in the order listed below.
  Each service runs in its own terminal window.
================================================================


PREREQUISITES
─────────────
  • Node.js  v18+   (https://nodejs.org)
  • Python   3.10+  (https://www.python.org)
  • PostgreSQL 15+  running locally (database: DermaAi)
  • Expo CLI        npm install -g expo-cli  (for mobile app)
  • Git             (optional, for version control)

  All .env files are already configured — no setup needed.


================================================================
  STEP 1 — PATIENT BACKEND  (Node.js / Express / Prisma)
================================================================
  Port : 5000
  Folder: Back-End/Patient/

  > cd "Back-End/Patient"
  > npm install          (first time only)
  > npm run dev

  ✓ Ready when you see: "Server running on port 5000"

  Handles: patient & doctor login, registration, profiles,
           consultations, token purchases, premium status.


================================================================
  STEP 2 — DOCTOR BACKEND  (Node.js / Express / Prisma)
================================================================
  Port : 5002
  Folder: Back-End/Doctor/

  > cd "Back-End/Doctor"
  > npm install          (first time only)
  > npm run dev

  ✓ Ready when you see: "Server running on port 5002"

  Handles: doctor-specific routes (appointments, etc.)
  NOTE: Doctor login now goes through Patient Backend (port 5000).


================================================================
  STEP 3 — SKIN DIAGNOSIS PIPELINE  (Python / FastAPI)
================================================================
  Port : 8000
  Folder: Skin_Diagnosis_Pipeline/

  > cd "Skin_Diagnosis_Pipeline"
  > pip install -r requirements.txt   (first time only)
  > uvicorn fastapi_app:app --host 0.0.0.0 --port 8000

  ✓ Ready when you see: "Application startup complete."

  Handles: AI skin disease detection (3-stage ML pipeline).
           Called by the patient mobile app when scanning.

  Health check: http://localhost:8000/health
  Disease list: http://localhost:8000/classes


================================================================
  STEP 4 — CHATBOT API  (Python / FastAPI / RAG)
================================================================
  Port : 8001
  Folder: Chatbot/

  > cd "Chatbot"
  > pip install -r requirements.txt   (first time only)
  > uvicorn chatbot_api:app --host 0.0.0.0 --port 8001

  ✓ Ready when you see: "Application startup complete."

  Handles: RAG-based skin disease Q&A chatbot.
           Called by the patient mobile app chat screen.

  Optional Streamlit UI (standalone chatbot web interface):
  > streamlit run app.py
  Opens at: http://localhost:8501


================================================================
  STEP 5 — DASHBOARD BACKEND  (Node.js)
================================================================
  Port : 5001
  Folder: Skin-diagnose-dashboard/dashboard-backend/

  > cd "Skin-diagnose-dashboard/dashboard-backend"
  > npm install          (first time only)
  > npm run dev

  ✓ Ready when you see: server started on port 5001


================================================================
  STEP 6 — SKIN DIAGNOSE DASHBOARD  (React / Vite)
================================================================
  Folder: Skin-diagnose-dashboard/dashboard/

  > cd "Skin-diagnose-dashboard/dashboard"
  > npm install          (first time only)
  > npm run dev

  ✓ Opens at: http://localhost:5173   (or similar Vite port)

  Admin/analytics dashboard for monitoring diagnoses.


================================================================
  STEP 7 — PATIENT MOBILE APP  (React Native / Expo)
================================================================
  Folder: Front-End/

  > cd "Front-End"
  > npm install          (first time only)

  ── Option A: Open directly in web browser ──────────────────
  > npx expo start --web
  ✓ Opens automatically at: http://localhost:8082

  ── Option B: Interactive menu (choose platform) ────────────
  > npx expo start
    [w] — Open in web browser  (http://localhost:8082)
    [a] — Open on Android emulator
    [i] — Open on iOS simulator
    Scan QR code with Expo Go app to test on a real phone

  ⚠ IMPORTANT — Physical phone setup:
    Open:  Front-End/src/config/api.ts
    Find:  const HOST = Platform.OS === 'web' ? 'localhost' : '192.168.1.2';
    Change 192.168.1.2  →  your PC's local IP address
    (Find your IP: run  ipconfig  in Windows CMD, look for IPv4 Address)


================================================================
  STEP 8 — DOCTOR WEB APP  (React Native Web / Expo)
================================================================
  Folder: Front-End-Doctor/

  > cd "Front-End-Doctor"
  > npm install          (first time only)
  > npx expo start --web

  ✓ Opens at: http://localhost:8083

  Both doctors AND patients can log in here.
  The app detects the role from the server and shows
  the correct interface automatically.

================================================================

================================================================
  TROUBLESHOOTING
================================================================
  "Cannot connect to server" on phone
    → Update the IP in Front-End/src/config/api.ts  (see Step 7)
    → Make sure your phone and PC are on the same Wi-Fi network

  "Database connection failed"
    → Make sure PostgreSQL is running
    → Check credentials in Back-End/Patient/.env

  "Module not found" (Node)
    → Run  npm install  inside that service folder

  "ModuleNotFoundError" (Python)
    → Run  pip install -r requirements.txt  inside that folder

  Expo port already in use
    → Kill the old process or use:  npx expo start --port 8084
